Fastest Zoho upload (Apps Script)

Uses the same Zoho Self Client already powering Calendar → Zoho. CRM only — no emails sent. Lead Source = Partner Outreach.

  1. Open script.google.com → New project (or your existing Calendar → Zoho project).
  2. Paste PartnerOutreachStandalone.gs.txt (or PartnerOutreach.gs.txt into the existing project).
  3. Project Settings → Script properties → set:
    • ZOHO_CLIENT_ID
    • ZOHO_CLIENT_SECRET
    • ZOHO_REFRESH_TOKEN
    • OUTREACH_SECRET (long random string you invent)
  4. Deploy → New deployment → Web app → Execute as Me, Who has access Anyone → copy the /exec URL.
  5. Open zoho-upload.html, paste URL + secret, upload Day 1.
  6. In Zoho CRM, confirm Lead Source picklist includes Partner Outreach (add it once if missing).
