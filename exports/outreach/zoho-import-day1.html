Upload Day 1 partners to Zoho

Keeps mattress customers separate: set Lead Source = Partner Outreach (not Web Download).

1. Download Day 1 CSV 2. Open Zoho CRM 3. After import → start conversations

Import steps (phone or desktop)

  1. Zoho CRM → Leads → Import (⋯ menu on mobile).
  2. Upload day1-zoho-leads-import.csv.
  3. Map fields using the table below.
  4. If Partner Outreach is missing from Lead Source: Setup → Modules and Fields → Leads → Lead Source → add that exact value → resume import.
  5. Finish import. Confirm you see Sharp Water Solutions with Lead Source Partner Outreach.
