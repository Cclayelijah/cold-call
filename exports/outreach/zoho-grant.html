Authorize Zoho in ~2 minutes

Use a Self Client grant token so Day 1 uploads as Lead Source Partner Outreach without saving secrets in chat.

  1. Open Zoho API Console → your Self Client.
  2. Generate a grant token with scope ZohoCRM.modules.ALL (and ZohoCRM.settings.ALL if offered).
  3. Copy Client ID, Client Secret, and the grant token (expires in minutes).
  4. Paste into admin /admin/outreach → Upload with grant token.
  5. Or from this agent environment: 
    ZOHO_CLIENT_ID=… ZOHO_CLIENT_SECRET=… ZOHO_GRANT_TOKEN=… \
  node scripts/upload-day-to-zoho.mjs 1
